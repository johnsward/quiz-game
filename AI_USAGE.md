# AI usage

All the ideas implemented in this project are our own. AI was used as a tool to help us work on them.

## Where AI was used

- **The original app:** AI was used when writing the original application.
- **Design phase:** AI was used as a companion to discuss our ideas, for example how to structure the environments and the pipelines.
- **Terraform scripts:** AI helped us write the Terraform code that describes the environments.
- **Bash scripts in the pipelines:** AI helped us write the bash parts of the workflows and the helper scripts.
- **Debugging:** AI was used extensively to debug problems, for example by reading pipeline logs and error messages and suggesting possible causes and fixes.
- **Documentation:** AI helped us write comprehensive README files, so that someone who forks the repository can follow them and run everything.

## Our responsibility

We reviewed the generated content, ran it, and tested the pipelines ourselves. We are responsible for everything in this repository.
